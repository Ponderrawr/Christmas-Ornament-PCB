# Hardware files

Export these from Altium and commit them here:

| File | How to export |
|---|---|
| `altium/` | The whole project folder (`.PrjPcb`, `.SchDoc`, `.PcbDoc`) |
| `schematic.pdf` | File → Smart PDF |
| `gerbers/` (zipped) | File → Fabrication Outputs → Gerber + NC Drill (mm, 4:3, matching origin) |
| `bom.csv` | Reports → Bill of Materials |
| `board.step` | File → Export → STEP 3D (lets people check plate fit) |
| `pcb_render.png` | 3D view screenshot, front and back |
